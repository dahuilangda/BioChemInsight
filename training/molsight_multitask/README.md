`edges.py` builds chemical adjacency targets from the validated literal-SMILES graph annotations. It uses classes none/single/double/triple/aromatic, masks self pairs, and rejects unsupported bond types explicitly. The loss groups the existing MolSight head's single-bond classes 1/5/6, because chemical SMILES alone does not establish the drawing's ordinary/wedge/dash class. It balances positive and negative pair means per supervised image and returns a summed objective plus valid-image denominator for explicit distributed normalization. This prevents quadratic none-pair counts from dominating large molecules.

A chemical-only trained head must not be decoded with the old seven-way argmax as if it had learned drawing stereochemistry: use the grouped chemical probabilities for topology diagnostics. Complete stereo identity continues to come from the full SMILES/semantic graph until actual drawing-direction supervision has been supplied and validated.

`preflight.py` extends a real checkpoint by an explicit allowlist of four edge-head parameters, verifies complete coverage of all original tensors, and backpropagates the chemical edge objective through a real training image. It performs no optimizer update and verifies that original state remains unchanged. Actual CPU report: `output/molsight_training_audit/chemical_edge_real_checkpoint_cpu_preflight.json`. This establishes one real backward path, not BF16/DDP stability, long-cyclic memory behavior or recognition improvement.
