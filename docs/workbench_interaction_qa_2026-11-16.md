# 工作台交互与规模测试

本次聚焦文献审阅中的实际操作：PDF 画框 → 解析 → 表格纠错 → 保存 → 审计恢复。参考 [Airtable 官方快捷键](https://support.airtable.com/articles/7980233311-airtable-keyboard-shortcuts) 的搜索、过滤、排序、编辑和帮助入口，同时保留文本输入的原生方向键、撤销和组合输入行为。

## 用户如何操作

1. 在 Review 中点击结果，可查看对应 PDF 页与来源区域；上下箭头也可以切换结果。
2. 点击 **Draw box** 或按 **B**。在 PDF 上拖出绿色框；原有来源定位框保持独立颜色。
3. 拖动框体可移动，拖动四角可缩放。PDF 有焦点时，方向键每次微调 1 个显示像素，Shift + 方向键微调 10 个显示像素。反向拖动、跨越原角点、拖到页面边缘均有边界约束。
4. 选择 **Structure**、**Result table** 或 **Scaffold / fragment**。表格应包含列名、单位和化合物标识；结构应包含一个完整目标。
5. 默认新增记录。选中已有记录后，可以明确勾选 Replace structure；修改目标时会清除旧的替换选择。
6. 点击 **Recognize / Extract rows**，或者在 PDF 区域按 **Ctrl/⌘ Enter**。画框和调整本身不会发起解析，也不会修改结果。
7. 结构解析后可在编辑器中检查，测量结果可在列表中纠正；自动保存后，可以通过 **History** 查看前后值或恢复。

Esc 取消画框。解析失败保留选框和错误信息，并恢复 PDF 焦点，便于重试。解析进行中不重复提交。目标记录被删除或任务被切换后，返回结果不会写入另一条记录。

手机进入画框模式时临时扩大 PDF 区域；退出后恢复原来的 PDF/结果比例。已有 PDF 折叠时，B 会展开并进入画框。触摸拖框与鼠标使用相同的归一化坐标逻辑。

## 快捷键

| 快捷键 | 行为 |
|---|---|
| B | 进入/退出画框 |
| Ctrl/⌘ Enter | 在 PDF 区域确认解析选框 |
| Esc | 取消字段编辑、选框，或关闭当前浮层 |
| Ctrl/⌘ F | 搜索结果；文本编辑器保留自身行为 |
| Ctrl/⌘ Shift F | 打开过滤 |
| Ctrl/⌘ Shift S | 打开排序并聚焦排序列 |
| Ctrl/⌘ Shift H | 打开修改历史 |
| Ctrl/⌘ S | 提交当前输入并等待保存 |
| Ctrl/⌘ / 或 ? | 查看帮助 |
| ↑ / ↓ | 非输入状态下切换结果并联动来源 |
| Enter / F2 | 编辑选中的结果 |
| Tab / Shift Tab | 在字段和控件之间移动 |
| Alt + ↑ / ↓ | 行拖动柄获得焦点时移动行 |
| Alt + ← / → | 列头获得焦点时移动列 |

帮助使用独立弹层和焦点约束，避免被手机 PDF 工具条或通知遮挡。化合物 ID 与测量输入统一支持 Enter 保存、Esc 放弃当前输入。

## 测试与发现

- 15 组 Chromium 浏览器回归：加载、切换、阶段选择、卡片/表格、行列拖动、列宽、分页、审计恢复、异步保存、导出、PDF 导航、按需下载、阅读优先级，以及新增快捷键/画框场景。
- 101 项后端单元测试通过；本次未替换识别模型或权重。
- 2,500 条结果和 64 页真实 PDF.js 文档的隔离交互测试：搜索、排序、编辑、输入保护、立即保存、画框/移动/缩放/键盘微调、失败重试、表格结果关联、目标删除保护、手机帮助及原生 Chromium 触摸拖框。
- 40 次保存、每次 2,500 条变更，合计 100,000 条记录变更的审计界面测试：初始仅渲染 30 次保存；关闭的修订不挂载字段，单次展开先显示 100 条记录，可继续加载。仍可搜索后面的值。日志传输和搜索目前仍在完整历史数据上进行，这不是无限规模历史服务的基准。
- 10,000 条记录、12 个测量字段、5,000 次固定种子的随机修改：差异与独立预期一致；32 次选择性恢复保留其他记录；兼容读取 20 份旧快照。同机差异计算约 30 ms，20 份历史读取约 0.92 s，仅为本机参考。
- 20,000 组固定种子几何输入，120,000 次主要变换调用：检查反向绘制、移动保持大小、四角缩放、边界和有限值。
- 界面检查包含 320–1920 px 多种宽度和短横屏，实际加载 JSME 控件；不是只检查静态 HTML。

测试修复了实际问题：解析失败后焦点丢失、解析期间目标行删除导致潜在误写、修改过程中立即 Ctrl/⌘ S 可能清掉定时保存却没有提交、手机浮层被 PDF 工具条遮挡、画框说明挤占 PDF 画布，以及大型审计列表一次挂载过多字段。

这些规模数据是隔离的接口/交互和存储测试，不代表模型解析准确率。当前自动浏览器验证为 Chromium，未宣称完成 Safari、Firefox 或真实 iOS 系统验证。SR 生产任务仅进行只读画框预览与截图，没有执行测试解析或恢复。
